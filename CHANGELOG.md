# Changelog

All notable changes to this project are documented here. It follows [Semantic Versioning](https://semver.org).

## 1.0.0

First release.

- **Media tool**: browse images and files in a grid or list, sorted newest, oldest, by name or largest, with live updates.
- **Search** across file names, titles, alt text and descriptions.
- **Filters**: type, categories (any, all, or none), orientation, file size and upload date, shown as removable chips.
- **Needs attention** views: images missing alt text, and assets nothing uses (drafts and release versions count).
- **Upload** by button or drag and drop, into the category that's showing.
- **Asset panel**: preview, copy URL, download, title, alt text, description, categories, details and where it's used.
- **Replace file** everywhere it's used, carrying over its title, alt text, description and categories.
- **Bulk actions**: add to or remove from categories, and delete, for many assets at once.
- **Categories**: create, rename and delete.
- **Picker** for image and file fields.
- Reads and writes the same data as sanity-plugin-media, so switching needs no migration.
